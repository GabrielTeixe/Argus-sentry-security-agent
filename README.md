 About the Project

Argus Sentry is an AI-powered autonomous cybersecurity agent capable of monitoring network traffic, detecting threats, and executing automated defensive actions.

The system simulates an automated Security Operations Center (SOC) where an intelligent agent analyzes events in real time and reacts without human intervention.

 Network traffic monitoring
 Threat classification
 Detection of:

Brute Force attacks

 Sobre o Projeto

O Argus Sentry é um agente autônomo de cibersegurança baseado em Inteligência Artificial capaz de monitorar tráfego de rede, detectar ameaças e executar respostas defensivas automaticamente.

O sistema simula um SOC automatizado (Security Operations Center) onde um agente inteligente analisa eventos em tempo real e toma decisões sem intervenção humana.

O objetivo do projeto é demonstrar conceitos modernos de:

Cybersecurity Automation
Intelligent Monitoring
Autonomous Agents
AI aplicada à segurança ofensiva e defensiva
 O que o sistema faz

 Monitora eventos de tráfego
 Classifica atividades como benignas ou ataques
 Detecta padrões como:

Brute Force
Tráfego suspeito
Eventos anômalos

 Calcula nível de risco
 Ativa defesa automática
 Bloqueia IP malicioso
 Registra incidentes
 Aprende com ataques detectados (quando suportado pelo modelo)
